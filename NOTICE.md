# Notice: origin, authorship and AI-agent use

This project began as **the author's own original idea** and was implemented
primarily by **AI coding agents** under the author's direction.

- **Origin and provenance.** The concept — turning several recordings of one
  event into a single **attributable** record — is the author's own original
  idea. It predates this repository and had an **earlier company-side
  implementation**, which is not the author's to release and is **not** the
  basis of this repository. This repository is an independent, **clean-room**
  reimplementation ([ADR-0001](docs/adr/0001-project-identity-and-provenance.md);
  see also [`docs/architecture.md`](docs/architecture.md) §6).
- **No company material imported.** No company source code, generated artifacts,
  specifications, recordings, datasets, partner names, internal documents or
  credentials are imported into this repository, and it is not developed as
  company work. Private input assets used to exercise the tool with real content
  are kept **out of the repository** — environment-local and never committed
  ([ADR-0006](docs/adr/0006-private-data-boundary.md)).
- **Agent use — not hidden.** Most of the code, tests and documentation were
  written by AI coding agents that the author directed and reviewed: the author
  set the approach and the acceptance criteria, drove the review gates, and
  accepts responsibility for the result; the agents did the legwork. The commit
  history and the test suite stand on their own — judge the diff, not who or what
  typed it.
- **Personally funded.** The project was built on the author's own time, hardware
  and resources. There is no employer funding or sponsorship of *this*
  repository.

This notice records facts as the author states them. It is **not a legal
opinion**. See [`PRIVACY.md`](PRIVACY.md) for the data-handling story.
